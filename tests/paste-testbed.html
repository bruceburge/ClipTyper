Paste Blocker Test Bed

Eleven fields, eleven ways real apps refuse a paste. Built to test ClipTyper, which types instead.

How to run a test

  1. Copy the test string below. It is loaded with layout troublemakers: braces, backslash, tilde, caret, and a euro sign.
  2. Click a field and try a normal paste (Ctrl+V, Shift+Insert, or right-click, Paste). Note what happens.
  3. Clear the field, click it again, and press Ctrl+Alt+V with ClipTyper running so it types the string instead.
  4. Hit Check on that case. Exact match means every character landed, in order.

The expectation line on each case is a prediction, not a promise. The check is the verdict. A few cases are designed to mangle or truncate no matter what you do, and those are labeled.

Works offline straight from disk. Open it in any browser. The one case no tool can fully beat is a field whose own code rewrites what lands in it (cases 8 and 9): the keystrokes arrive fine, the field itself does the damage.
